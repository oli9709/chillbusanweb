🐛 Sentry Integration Test

Test Sentry error tracking and verify events are being captured

📋 Instructions

  1. Make sure SENTRY_DSN is set in your Vercel environment variables
  2. Click "Trigger API Error" button below (this is the easiest test)
  3. Check your Sentry Dashboard → Issues tab
  4. Events should appear within 10-30 seconds
  5. Look for error with tag: test: sentry_verification

💡 Tip: If you don't see events, wait 30 seconds and refresh your Sentry dashboard. Events are batched and may take a moment to appear.

1. Client-side JavaScript Error

Triggers an undefined function error in the browser

2. Server-side API Error

Calls an API endpoint that throws an error (captured by Sentry on server)

3. Custom Error Message

Sends a custom error message to Sentry

4. Error with Context

Triggers an error with additional context data
